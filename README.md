# 极简记物 APP

一款轻量极简的个人物品管理应用，帮助你记录物品信息并计算日均使用成本。

## ✨ 功能特性

### 核心功能
- **物品管理**：添加、编辑、删除物品信息
- **日均价计算**：自动计算单品日均价格（购入价 ÷ 使用天数）
- **数据可视化**：展示物品日均价分布图表
- **分类管理**：自定义物品分类（数码、服饰、家居等）

### 实用功能
- 快速搜索物品
- 支持按日均价、购入时间、价格排序
- 本地数据存储（localStorage）
- 资产统计（购入总价、总日均价格）

## 🚀 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **路由**：React Router
- **图表**：Recharts
- **样式**：CSS Variables
- **存储**：localStorage

## 📦 安装与运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 📱 界面预览

### 首页
- 顶部展示核心数据：总日均价格、物品总数
- 卡片式陈列所有物品，显示名称、购入价、已使用天数、日均价
- 支持快速搜索和排序

### 统计页
- 统计卡片：总日均价格、购入总价
- 柱状图展示各类别日均价占比
- 分类明细统计

## 🎯 使用说明

1. **添加物品**：点击底部"+"按钮，填写物品名称、分类、购入价格、购买日期
2. **查看统计**：点击底部"统计"标签，查看资产概览和图表
3. **管理分类**：在首页点击"管理分类"，可创建、编辑、删除分类
4. **搜索物品**：在首页搜索框输入关键词快速查找
